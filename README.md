### ⚡ Right now

Building a **zero-trust authorization framework for multi-agent AI** (my thesis).
A deterministic **Cedar** policy engine sits behind **mTLS sidecars** and decides every agent-to-agent call. LLMs only *propose* policies; they never get the final say.
